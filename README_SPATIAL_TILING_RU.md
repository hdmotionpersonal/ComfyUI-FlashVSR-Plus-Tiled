# FlashVSR+ T8 Spatial Tiling — рабочая копия форка

Этот файл описывает планируемую функцию пространственного тайлинга. В текущей версии upstream параметр `vae_tiled` относится к декодеру Wan VAE; он не включает разбиение основного DiT на тайлы.

## Настройки

Поля добавлены в существующую `FlashVSR+ Options`. Они задают включение тайлинга, размер тайла и overlap в пикселях целевого canvas, а также способ смешивания:

- `cosine` — плавная косинусная растушёвка;
- `linear` — линейный переход;
- `gaussian` — больший вес центра тайла, с настройкой sigma.

Для всех вариантов веса соседних предсказаний нормируются по сумме. На внешней границе кадра вес должен оставаться полным. GPU-проверенный старт: 512 px tile, 128 px overlap, cosine. На другой карте и backend больший tile может быть быстрее; проверяйте доступную VRAM и SDPA preflight.

## Реализовано сейчас

- IMAGE путь строит сетку, запускает один tile за раз через FlashVSR+ и собирает результат нормированными весами. Цветовая коррекция применяется после сшивки.
- Cosine, Linear и Gaussian доступны из Options.
- При выключенном тайлинге остаётся обычный единичный вызов модели.

## Ограничения текущей стадии

- VIDEO tiling поддерживает Tiny decoder с числовым `decode_every`, пишет float16 сегменты на временный диск и требует место пропорционально длине клипа и суммарной площади overlap. Wan VAE spatial path пока не поддержан.
- одинаковый seed создаёт общее глобальное latent-шумовое окно для каждого временного блока; тайл берёт crop по координатам canvas.
- Выход модели всё ещё может отличаться из-за ограниченного контекста внимания внутри каждого тайла.
- Color correction в VIDEO выполняется для каждого тайла отдельно; если заметен цветовой стык, отключите её.

## GPU smoke check

Локальный прогон на RTX 4070 Ti SUPER: V1 INT8 + Tiny + SDPA, `demo1.mp4` (400×224, 33 кадра, 24 FPS), целевой размер 1600×896. VIDEO и IMAGE прошли с 8 тайлами 512 px и overlap 128 px; VIDEO сохранил 33 кадра, 24 FPS и AAC audio. Float16 spool занял 415 MB против 830 MB у float32. Декодированные результаты двух mp4 побайтно совпали на всех 33 кадрах (uint8 MAE 0). Все три blend режима точно сохраняют константное поле в CPU-проверке.

Native BSA в этой ComfyUI-среде не установлен. Triton backend импортировался, но Windows JIT-драйвер не собрал вспомогательный модуль; режим `auto` перешёл на SDPA. Большие SDPA tiles могут не пройти memory preflight, уменьшите tile size.
- Tile-inference пока не проверялся на GPU и не считается готовым к выпуску. Перед использованием проверьте рабочую копию на копии workflow.
