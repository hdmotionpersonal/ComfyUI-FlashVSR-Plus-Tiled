# FlashVSR+ T8 Spatial Tiling — рабочая копия форка

Этот файл описывает планируемую функцию пространственного тайлинга. В текущей версии upstream параметр `vae_tiled` относится к декодеру Wan VAE; он не включает разбиение основного DiT на тайлы.

## Параметры будущей ноды

Планируемая нода `FlashVSR+ Spatial Tiling Options` будет задавать включение тайлинга, размер тайла и overlap в пикселях целевого canvas, а также способ смешивания:

- `cosine` — плавная косинусная растушёвка;
- `linear` — линейный переход;
- `gaussian` — больший вес центра тайла, с настройкой sigma.

Для всех вариантов веса соседних предсказаний нормируются по сумме. На внешней границе кадра вес должен оставаться полным. Начальные значения для GPU-проверки: 1024 px tile, 128 px overlap, cosine. Они ещё не подтверждены практическими замерами качества или VRAM.
